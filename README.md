# Brain-Tumor-Classification-Logistic-Regression-and-FNN
The repository contains the codes to perform a One-Versus-All Framework in Classifying Brain Tumors from a pre-extracted Radiomics Feature. The repository also contains a simple architecture for a Feedforward Neural Network.

The dataset used in this paper contains 233 unique patients with a total of 3064 T1-weighted contrast-enhanced images taken from https://figshare.com/articles/dataset/brain_tumor_dataset/1512427
